# Linux agent

A Linux-agent tervezett forráshelye: systemd szolgáltatás, helyi IPC és Linux-integráció. A kapcsolatot, a verzióegyeztetést és az újracsatlakozást az [`agent-core`](../agent-core) adja ([agentprotokoll](../../docs/agent-protokoll.md)).

A megvalósítás és a támogatott disztribúciókon végzett próbák még hátravannak. Követelmények: [agent és platformok](../../docs/kovetelmenyek.md).

## English

Planned source directory for the Linux agent: systemd service, local IPC and Linux integration. Connection, version negotiation and reconnection come from [`agent-core`](../agent-core) ([agent protocol](../../docs/agent-protokoll.md#english)).

Implementation and tests on supported distributions remain pending. See the [agent and platform requirements](../../docs/kovetelmenyek.md#english).

# Linux agent

A Linux-agent tervezett forráshelye: systemd szolgáltatás, helyi IPC és Linux-integráció. A közös protokoll és ütemezés az agent közös moduljából származik majd.

A megvalósítás és a támogatott disztribúciókon végzett próbák még hátravannak. Követelmények: [agent és platformok](../../docs/kovetelmenyek.md).

## English

Planned source directory for the Linux agent: systemd service, local IPC and Linux integration. Protocol handling and scheduling will use the common agent module.

Implementation and tests on supported distributions remain pending. See the [agent and platform requirements](../../docs/kovetelmenyek.md#english).
